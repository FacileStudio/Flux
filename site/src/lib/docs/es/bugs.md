# Informar de un error

Flux está en beta: sus comentarios cuentan.

Abra una incidencia en [GitHub](https://github.com/FacileStudio/Flux/issues) con:

- lo que estaba haciendo
- lo que pasó y lo que esperaba
- su equipo (procesador, tarjeta gráfica)
- la salida de `nixos-version`

Una captura de pantalla suele ayudar.
