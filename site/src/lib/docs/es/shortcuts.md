# Atajos de teclado

**Mod** es la tecla Super (Windows o Cmd).

| Atajo | Acción |
|---|---|
| Mod+Intro | Abrir el terminal |
| Mod+D o Mod+Espacio | Abrir el lanzador |
| Mod+N | Abrir el panel lateral |
| Mod+Esc | Menú de salida |
| Mod+Q | Cerrar la ventana |
| Mod+H / Mod+L | Columna de la izquierda / derecha |
| Mod+Mayús+/ | Mostrar todos los atajos |
