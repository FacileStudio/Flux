# Atajos de teclado

**Mod** es la tecla Super: la tecla Windows en la mayoría de los teclados, Cmd en un teclado Mac.

Pulse **Mod+Mayús+/** en cualquier momento para ver los atajos principales en pantalla.

## Uso diario

| Atajo | Acción |
|---|---|
| Mod+Espacio | Abrir una aplicación |
| Mod+Intro | Abrir el terminal |
| Mod+E | Abrir sus archivos |
| Mod+Coma | Abrir los Ajustes |
| Mod+N | Notificaciones y ajustes rápidos |
| Mod+Mayús+V | Historial del portapapeles |
| Mod+L | Bloquear la pantalla |
| Mod+Esc | Cerrar sesión, reiniciar o apagar |
| Impr Pant o Mod+Mayús+S | Capturar una zona de la pantalla |
| Ctrl+Impr Pant | Capturar la pantalla |
| Alt+Impr Pant | Capturar la ventana |

## Ventanas

| Atajo | Acción |
|---|---|
| Mod+Q o Alt+F4 | Cerrar la ventana |
| Alt+Tab | Volver a la ventana anterior |
| Mod+Tab o Mod+O | Ver todas las ventanas y áreas de trabajo |
| Mod+Izquierda / Mod+Derecha | Ir a la ventana de la izquierda / derecha |
| Mod+Arriba / Mod+Abajo | Ir a la ventana de arriba / abajo |
| Mod+Inicio / Mod+Fin | Ir a la primera / última ventana de la fila |
| Mod+Mayús+flecha | Mover la ventana en esa dirección |
| Mod+F | Dar a la ventana todo el ancho |
| Mod+Mayús+F | Pantalla completa |
| Mod+R | Alternar entre la mitad, dos tercios y todo el ancho |
| Mod+Menos / Mod+Igual | Estrechar / ensanchar la ventana |
| Mod+C | Centrar la ventana |
| Mod+V | Hacer flotar la ventana, o devolverla a la fila |
| Mod+[ / Mod+] | Apilar la ventana con su vecina, o sacarla |
| Mod+W | Mostrar una pila de ventanas como pestañas |

## Áreas de trabajo y pantallas

| Atajo | Acción |
|---|---|
| Mod+1 a Mod+9 | Ir a un área de trabajo |
| Mod+Mayús+1 a Mod+Mayús+9 | Mover la ventana a un área de trabajo |
| Mod+U / Mod+I | Ir al área de trabajo de abajo / arriba |
| Mod+Ctrl+H, J, K, L | Ir a la pantalla de la izquierda, abajo, arriba, derecha |
| Mod+Mayús+Ctrl+H, J, K, L | Mover la ventana a esa pantalla |
| Mod+Mayús+P | Apagar las pantallas hasta la próxima tecla |

## Teclas al estilo Vim

| Atajo | Acción |
|---|---|
| Mod+Alt+H, J, K, L | Ir a la ventana de la izquierda, abajo, arriba, derecha |
| Mod+Mayús+H, J, K, L | Mover la ventana en esa dirección |

Mod+L iba antes a la ventana de la derecha. Ahora bloquea la pantalla, como en Windows. Mod+Alt+L ocupa su lugar, y Super+Alt+L ya no bloquea.
