# First boot

Flux starts on the niri desktop, with the status bar at the top.

- **Mod+Return** opens the Ghostty terminal.
- **Mod+D** or **Mod+Space** opens the launcher.
- **Mod+Shift+/** shows every shortcut.

**Mod** is the Super key (Windows or Cmd).

Every Facile tool is already installed. Run `sablier`, `nuage` or `casier` in the terminal, then sign in with your Facile account.

Change the password with `passwd`.
