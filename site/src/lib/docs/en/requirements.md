# Requirements

Flux runs on most recent computers. You need:

- a computer that boots in **UEFI** mode
- an **x86_64** (Intel or AMD) or **ARM64** processor
- **4 GB** of RAM
- **20 GB** of disk space
- a USB stick of 4 GB or more for the install

The install erases the disk you pick. Back up your files first.

Flux is in open beta. The stable version comes around March 2027.
