# Keyboard shortcuts

**Mod** is the Super key: the Windows key on most keyboards, Cmd on a Mac keyboard.

Press **Mod+Shift+/** at any time to see the main shortcuts on screen.

## Everyday

| Shortcut | Action |
|---|---|
| Mod+Space | Open an app |
| Mod+Return | Open the terminal |
| Mod+E | Open your files |
| Mod+Comma | Open Settings |
| Mod+N | Notifications and quick settings |
| Mod+Shift+V | Clipboard history |
| Mod+L | Lock the screen |
| Mod+Escape | Sign out, restart or shut down |
| Print or Mod+Shift+S | Take a screenshot of an area |
| Ctrl+Print | Take a screenshot of the screen |
| Alt+Print | Take a screenshot of the window |

## Windows

| Shortcut | Action |
|---|---|
| Mod+Q or Alt+F4 | Close the window |
| Alt+Tab | Go back to the previous window |
| Mod+Tab or Mod+O | Show every window and workspace |
| Mod+Left / Mod+Right | Go to the window on the left / right |
| Mod+Up / Mod+Down | Go to the window above / below |
| Mod+Home / Mod+End | Go to the first / last window of the row |
| Mod+Shift+arrow | Move the window that way |
| Mod+F | Give the window the full width |
| Mod+Shift+F | Full screen |
| Mod+R | Switch between half, two thirds and full width |
| Mod+Minus / Mod+Equal | Make the window narrower / wider |
| Mod+C | Center the window |
| Mod+V | Float the window, or put it back in the row |
| Mod+[ / Mod+] | Stack the window with its neighbour, or take it out |
| Mod+W | Show a stack of windows as tabs |

## Workspaces and screens

| Shortcut | Action |
|---|---|
| Mod+1 to Mod+9 | Go to a workspace |
| Mod+Shift+1 to Mod+Shift+9 | Move the window to a workspace |
| Mod+U / Mod+I | Go to the workspace below / above |
| Mod+Ctrl+H, J, K, L | Go to the screen on the left, below, above, right |
| Mod+Shift+Ctrl+H, J, K, L | Move the window to that screen |
| Mod+Shift+P | Turn the screens off until the next key press |

## Vim-style keys

| Shortcut | Action |
|---|---|
| Mod+Alt+H, J, K, L | Go to the window on the left, below, above, right |
| Mod+Shift+H, J, K, L | Move the window that way |

Mod+L used to go to the window on the right. It now locks the screen, as on Windows. Mod+Alt+L took over, and Super+Alt+L no longer locks.
