# Keyboard shortcuts

**Mod** is the Super key (Windows or Cmd).

| Shortcut | Action |
|---|---|
| Mod+Return | Open the terminal |
| Mod+D or Mod+Space | Open the launcher |
| Mod+N | Open the sidebar |
| Mod+Escape | Exit menu |
| Mod+Q | Close the window |
| Mod+H / Mod+L | Column to the left / right |
| Mod+Shift+/ | Show every shortcut |
