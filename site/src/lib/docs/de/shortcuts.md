# Tastenkürzel

**Mod** ist die Super-Taste: die Windows-Taste auf den meisten Tastaturen, Cmd auf einer Mac-Tastatur.

Drücken Sie jederzeit **Mod+Umschalt+/**, um die wichtigsten Tastenkürzel auf dem Bildschirm zu sehen.

## Alltag

| Kürzel | Aktion |
|---|---|
| Mod+Leertaste | Ein Programm öffnen |
| Mod+Eingabe | Terminal öffnen |
| Mod+E | Ihre Dateien öffnen |
| Mod+Komma | Einstellungen öffnen |
| Mod+N | Mitteilungen und Schnelleinstellungen |
| Mod+Umschalt+V | Verlauf der Zwischenablage |
| Mod+L | Bildschirm sperren |
| Mod+Esc | Abmelden, neu starten oder ausschalten |
| Druck oder Mod+Umschalt+S | Einen Bereich des Bildschirms aufnehmen |
| Strg+Druck | Den Bildschirm aufnehmen |
| Alt+Druck | Das Fenster aufnehmen |

## Fenster

| Kürzel | Aktion |
|---|---|
| Mod+Q oder Alt+F4 | Fenster schließen |
| Alt+Tab | Zum vorherigen Fenster zurück |
| Mod+Tab oder Mod+O | Alle Fenster und Arbeitsflächen zeigen |
| Mod+Links / Mod+Rechts | Zum Fenster links / rechts |
| Mod+Hoch / Mod+Runter | Zum Fenster darüber / darunter |
| Mod+Pos1 / Mod+Ende | Zum ersten / letzten Fenster der Reihe |
| Mod+Umschalt+Pfeil | Fenster in diese Richtung verschieben |
| Mod+F | Dem Fenster die ganze Breite geben |
| Mod+Umschalt+F | Vollbild |
| Mod+R | Zwischen halber, zwei Dritteln und ganzer Breite wechseln |
| Mod+Minus / Mod+Gleich | Fenster schmaler / breiter machen |
| Mod+C | Fenster zentrieren |
| Mod+V | Fenster schweben lassen oder zurück in die Reihe setzen |
| Mod+[ / Mod+] | Fenster mit dem Nachbarn stapeln oder herausnehmen |
| Mod+W | Einen Fensterstapel als Tabs zeigen |

## Arbeitsflächen und Bildschirme

| Kürzel | Aktion |
|---|---|
| Mod+1 bis Mod+9 | Zu einer Arbeitsfläche gehen |
| Mod+Umschalt+1 bis Mod+Umschalt+9 | Fenster auf eine Arbeitsfläche verschieben |
| Mod+U / Mod+I | Zur Arbeitsfläche darunter / darüber |
| Mod+Strg+H, J, K, L | Zum Bildschirm links, unten, oben, rechts |
| Mod+Umschalt+Strg+H, J, K, L | Fenster auf diesen Bildschirm verschieben |
| Mod+Umschalt+P | Bildschirme bis zum nächsten Tastendruck ausschalten |

## Tasten im Vim-Stil

| Kürzel | Aktion |
|---|---|
| Mod+Alt+H, J, K, L | Zum Fenster links, unten, oben, rechts |
| Mod+Umschalt+H, J, K, L | Fenster in diese Richtung verschieben |

Mod+L ging früher zum Fenster rechts. Jetzt sperrt es den Bildschirm, wie unter Windows. Mod+Alt+L hat diese Aufgabe übernommen, und Super+Alt+L sperrt nicht mehr.
