# Tastenkürzel

**Mod** ist die Super-Taste (Windows oder Cmd).

| Kürzel | Aktion |
|---|---|
| Mod+Eingabe | Terminal öffnen |
| Mod+D oder Mod+Leertaste | Starter öffnen |
| Mod+N | Seitenleiste öffnen |
| Mod+Esc | Beenden-Menü |
| Mod+Q | Fenster schließen |
| Mod+H / Mod+L | Spalte links / rechts |
| Mod+Umschalt+/ | Alle Tastenkürzel zeigen |
