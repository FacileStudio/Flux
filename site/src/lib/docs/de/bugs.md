# Fehler melden

Flux ist in der Beta, Ihre Rückmeldungen zählen.

Eröffnen Sie ein Issue auf [GitHub](https://github.com/FacileStudio/Flux/issues) mit:

- was Sie gerade getan haben
- was passiert ist und was Sie erwartet haben
- Ihrem Rechner (Prozessor, Grafikkarte)
- der Ausgabe von `nixos-version`

Ein Screenshot hilft oft.
