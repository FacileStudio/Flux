# Voraussetzungen

Flux läuft auf den meisten aktuellen Rechnern. Sie brauchen:

- einen Rechner, der im **UEFI**-Modus startet
- einen **x86_64**-Prozessor (Intel oder AMD) oder **ARM64**
- **4 GB** Arbeitsspeicher
- **20 GB** Speicherplatz
- einen USB-Stick mit 4 GB oder mehr für die Installation

Die Installation löscht die gewählte Festplatte. Sichern Sie vorher Ihre Dateien.

Flux ist in der offenen Beta. Die stabile Version kommt um März 2027.
