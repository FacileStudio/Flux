# Erster Start

Flux startet auf dem niri-Desktop, mit der Statusleiste oben.

- **Mod+Eingabe** öffnet das Terminal Ghostty.
- **Mod+D** oder **Mod+Leertaste** öffnet den Starter.
- **Mod+Umschalt+/** zeigt alle Tastenkürzel.

**Mod** ist die Super-Taste (Windows oder Cmd).

kit installiert bei der ersten Anmeldung alle Facile-Werkzeuge in Ihrem Konto und sucht einmal am Tag nach Updates. Entfernen Sie eines mit `kit del <werkzeug>`, fügen Sie eines mit `kit add <werkzeug>` hinzu. Starten Sie `sablier`, `nuage` oder `casier` im Terminal und melden Sie sich mit Ihrem Facile-Konto an.

Ändern Sie das Passwort mit `passwd`.
