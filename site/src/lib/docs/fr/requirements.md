# Configuration requise

Flux tourne sur la plupart des ordinateurs récents. Il vous faut :

- un ordinateur qui démarre en **UEFI** ;
- un processeur **x86_64** (Intel ou AMD), ou une machine **ARM64 UEFI** : une VM ou un serveur. L’ISO ARM ne démarre pas directement sur un Raspberry Pi standard ni sur un Mac Apple Silicon ;
- **4 Go** de mémoire vive ;
- **20 Go** d’espace disque ;
- une clé USB de 4 Go ou plus pour l’installation.

L’installation efface le disque que vous choisissez. Sauvegardez vos fichiers avant de commencer.

Flux est en bêta ouverte. La version stable arrive vers mars 2027.
