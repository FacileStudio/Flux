# Démarrer la session live

1. Branchez la clé et redémarrez l’ordinateur.
2. Ouvrez le menu de démarrage (souvent F12, F10 ou Échap au démarrage) et choisissez la clé USB.
3. Flux démarre et l’installateur s’ouvre. Choisissez **Essayer Flux** pour découvrir le système sans rien changer.

Si un écran de connexion apparaît :

- utilisateur : `flux`
- mot de passe : `flux`

La session live ne garde rien après l’arrêt. Profitez-en pour vérifier que l’écran, le Wi-Fi et le son marchent.
