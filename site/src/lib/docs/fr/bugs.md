# Signaler un bug

Flux est en bêta : vos retours comptent.

Ouvrez un ticket sur [GitHub](https://github.com/FacileStudio/Flux/issues) avec :

- ce que vous faisiez ;
- ce qui s’est passé, et ce que vous attendiez ;
- votre machine (processeur, carte graphique) ;
- la sortie de `nixos-version`.

Une capture d’écran aide souvent.
