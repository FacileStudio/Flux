# Raccourcis clavier

**Mod** est la touche Super (Windows ou Cmd).

| Raccourci | Action |
|---|---|
| Mod+Entrée | Ouvrir le terminal |
| Mod+D ou Mod+Espace | Ouvrir le lanceur |
| Mod+N | Ouvrir le panneau latéral |
| Mod+Échap | Menu de sortie |
| Mod+Q | Fermer la fenêtre |
| Mod+H / Mod+L | Colonne de gauche / de droite |
| Mod+Maj+/ | Afficher tous les raccourcis |
