# Raccourcis clavier

**Mod** est la touche Super : la touche Windows sur la plupart des claviers, Cmd sur un clavier Mac.

Appuyez sur **Mod+Maj+/** à tout moment pour voir les principaux raccourcis à l’écran.

## Au quotidien

| Raccourci | Action |
|---|---|
| Mod+Espace | Ouvrir une application |
| Mod+Entrée | Ouvrir le terminal |
| Mod+E | Ouvrir vos fichiers |
| Mod+Virgule | Ouvrir les Réglages |
| Mod+N | Notifications et réglages rapides |
| Mod+Maj+V | Historique du presse-papiers |
| Mod+L | Verrouiller l’écran |
| Mod+Échap | Se déconnecter, redémarrer ou éteindre |
| Impr. écran ou Mod+Maj+S | Capturer une zone de l’écran |
| Ctrl+Impr. écran | Capturer l’écran |
| Alt+Impr. écran | Capturer la fenêtre |

## Fenêtres

| Raccourci | Action |
|---|---|
| Mod+Q ou Alt+F4 | Fermer la fenêtre |
| Alt+Tab | Revenir à la fenêtre précédente |
| Mod+Tab ou Mod+O | Voir toutes les fenêtres et tous les espaces de travail |
| Mod+Gauche / Mod+Droite | Aller à la fenêtre de gauche / de droite |
| Mod+Haut / Mod+Bas | Aller à la fenêtre du dessus / du dessous |
| Mod+Début / Mod+Fin | Aller à la première / dernière fenêtre de la rangée |
| Mod+Maj+flèche | Déplacer la fenêtre dans ce sens |
| Mod+F | Donner toute la largeur à la fenêtre |
| Mod+Maj+F | Plein écran |
| Mod+R | Passer de la moitié aux deux tiers puis à toute la largeur |
| Mod+Moins / Mod+Égal | Rétrécir / élargir la fenêtre |
| Mod+C | Centrer la fenêtre |
| Mod+V | Rendre la fenêtre flottante, ou la remettre dans la rangée |
| Mod+[ / Mod+] | Empiler la fenêtre avec sa voisine, ou l’en sortir |
| Mod+W | Afficher une pile de fenêtres en onglets |

## Espaces de travail et écrans

| Raccourci | Action |
|---|---|
| Mod+1 à Mod+9 | Aller à un espace de travail |
| Mod+Maj+1 à Mod+Maj+9 | Déplacer la fenêtre vers un espace de travail |
| Mod+U / Mod+I | Aller à l’espace de travail du dessous / du dessus |
| Mod+Ctrl+H, J, K, L | Aller à l’écran de gauche, du dessous, du dessus, de droite |
| Mod+Maj+Ctrl+H, J, K, L | Déplacer la fenêtre vers cet écran |
| Mod+Maj+P | Éteindre les écrans jusqu’à la prochaine touche |

## Touches façon Vim

| Raccourci | Action |
|---|---|
| Mod+Alt+H, J, K, L | Aller à la fenêtre de gauche, du dessous, du dessus, de droite |
| Mod+Maj+H, J, K, L | Déplacer la fenêtre dans ce sens |

Mod+L allait à la fenêtre de droite. Il verrouille maintenant l’écran, comme sous Windows. Mod+Alt+L a pris sa place, et Super+Alt+L ne verrouille plus.
