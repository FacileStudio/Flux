# Premier démarrage

Flux démarre sur le bureau niri, avec la barre d’état en haut.

- **Mod+Entrée** ouvre le terminal Ghostty.
- **Mod+D** ou **Mod+Espace** ouvre le lanceur.
- **Mod+Maj+/** affiche tous les raccourcis.

La touche **Mod** est la touche Super (Windows ou Cmd).

kit installe tous les outils Facile dans votre compte à la première connexion, puis cherche les mises à jour toutes les heures. Retirez-en un avec `kit del <outil>`, ajoutez-en un avec `kit add <outil>`. Lancez par exemple `sablier`, `nuage` ou `casier` dans le terminal, puis connectez-vous avec votre compte Facile.

Pensez à changer le mot de passe avec `passwd`.
